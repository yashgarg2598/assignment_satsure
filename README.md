## Stack

Python + [pytest-playwright](https://playwright.dev/python/docs/test-runners) for UI,
`requests` + `jsonschema` for the API contract. Assertions rely on Playwright's auto-waiting
`expect` and on JSON Schema validation rather than hand-written checks, so there is no custom
waiting or per-field validation logic.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## Running

```bash
pytest              # whole suite: 18 passed, 6 xfailed
pytest -m ui        # Playwright UI tests only
pytest -m api       # API contract tests only
pytest -m ui --headed --slowmo 300   # watch the UI suite run
```

Expected output: **18 passed, 6 xfailed**. The 6 `xfail`s are the defects documented in
`docs/3-defect-identification.md`, asserted with `strict=True` against the exact payload from the
assignment — the suite stays green while a defect still reproduces and fails loudly the moment one
is fixed, at which point the marker is removed.

## Running against a real environment

Both suites are environment-driven; no code changes are needed.

| Variable | Default | Purpose |
|---|---|---|
| `BASE_URL` | local static server | Root of the web app, e.g. `https://test.com` |
| `API_BASE_URL` | local stub server | Root of the REST API |

```bash
BASE_URL=https://test.com API_BASE_URL=https://api.test.com pytest
```

## Test doubles (and why they exist)

`https://test.com/autocomplete-form` is not a real environment, but the assignment requires the
scripts to be executable. Two standard-library stand-ins make that true out of the box:

- `tests/ui/config/autocomplete-form.html` — the assignment's HTML structure verbatim (same ids,
  classes and copy) plus the minimum script to make FR-01…FR-04 observable, served over
  `http.server`. Filtering mode is prefix match by default and match-anywhere via
  `?match=anywhere` (FR-03). It is a **test double, not a deliverable** — none of the assertions
  depend on its implementation, only on the ids, classes and copy given in the assignment.
- `tests/api/tests/conftest.py` — an `http.server` stub returning the assignment's exact JSON,
  a corrected variant, and the three malformed variants the negative tests need.

The Next button's REST call is intercepted with Playwright's `page.route`, so the UI suite makes no
outbound network calls.
